# Code of Conduct

Afterhall adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Because Afterhall deals with death, grief and family memories, we also ask everyone to:

- treat discussions about loss and grief with care
- never share real personal data about others, living or deceased
- respect that people have very different views on digital legacy

Report unacceptable behaviour to **conduct@afterhall.app**. All reports are handled confidentially.
